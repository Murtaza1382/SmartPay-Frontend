# SmartPay Frontend

Frontend application for the SmartPay project.

## Overview

SmartPay is an educational payment processing application designed
to demonstrate the Strategy Design Pattern using multiple payment methods.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- Axios
- TanStack Query
- Lucide React

## Architecture

The application follows a feature-oriented architecture.

## Development

Install dependencies:

pnpm install

Run development server:

pnpm dev

Application:

http://localhost:3000

## Backend

The frontend communicates with the SmartPay ASP.NET Core backend through REST APIs.
